# 📚 Library Management System

一个图书馆管理系统（C++ + SQLite3(后续可能迁移至MySQL)）

---

## 使用说明

克隆项目到本地后，使用CMake编译即可运行。会自动创建数据库表。
由于文件上传功能正在施工但并未完善，克隆项目运行后可能会出错
